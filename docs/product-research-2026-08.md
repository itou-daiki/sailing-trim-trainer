# TRIM NOTE 公開製品・一次資料調査

調査日: 2026-08-24
対象: 420 / 470のセール形状学習Webアプリ
目的: 一般的なセーリングゲームではなく、形状コントロールの因果学習でカテゴリ最高水準を目指す。

## 結論

既存製品の強みは大きく4系統に分かれる。

1. VPP／ポーラを使った性能シミュレーション
2. 回転可能な3D艇・風・テルテールによる没入型練習
3. 課題・得点・段階進行によるゲーム型習熟
4. 写真のドラフトストライプを数値化するセールメーカー向け計測

TRIM NOTEは1〜3を薄く広く模倣せず、420/470固有コントロールと4の計測方法を学習ループへ統合する。中心価値は、**一本を動かす → 操作前と今を重ねる → どの断面がどう変わったか数値で言う → 基準形と照合する**ことに置く。

## 420 / 470の一次資料から固定した因果

- [North Sails Japan 420 M11/M12 Tuning Guide](https://www.northsails.co.jp/wordpress/wp-content/uploads/2026/03/420-M12-Tuning-Guide_j.pdf): アウトホールは下部の深さを変える。表の基準はブラックバンドから1–16 ktで20–25 mm、16–20 ktで10–15 mm、20 kt超で0–10 mm。チョックはバング使用時の下部形状、ジブ高さ／風上シーティングはリード角とリーチ形状に関係する。
- [North Sails 470 Tuning Guide](https://colorcode.northsails.com/sailing/wp-content/uploads/2017/05/470_tuning_guide_e01.pdf): カニンガムを引くと最大ドラフト位置が前へ移り、リーチが開いてフラットになる。アウトホールは0–5 m/sで通常ブラックバンドから10–15 mm、悪い波では最大25 mm、5 m/sを超えてオーバーパワーになればブラックバンドまで引く。ジブトラック後退はリーチを開く。
- [North Sails 470 Speed Guide](https://www.northsails.com/en-ca/blogs/north-sails-blog/470-speed-guide): メインはleech/twistを中心に見て、風・海面が増すとcunningham、outhaul、vangでデパワー。ダウンウインドはouthaul/cunninghamを緩め、リーチを開く。

アウトホールは抽象的な0–100%の「出し量」ではなく、ブラックバンドからの実寸距離へ換算する。操作範囲は0–25 mm、右端がブラックバンド（0 mm）である。ERS F.3.1は外側点を10 mm幅の外側リミットマークの艇首側端・ブーム上端と定義し、420/470規則は外側点距離をマスト後面から2400/2650 mmとする。このためクリューは常にその外側点から表示値と同じ距離だけ前へ置く。420表は10–16 ktの20–25 mmと16–20 ktの10–15 mmが16 ktで重複する一方、本文は「0–14ノット付近までは、同じセット」と説明する。そこで14 ktまでは22.5 mm、14–16 ktで22.5→15 mm、16–20 ktで15→10 mmへ連続的に引き込み、16 ktを弱風側22.5 mmへ固定していた境界誤差をなくす。470は通常海面の10–15 mmを基準とし、波を扱わない本モデルでは「悪い波」の25 mmを基準に採用しない。470のダウンウインドはSpeed Guideの定性的な「出す」に従うが15 mmを上限とし、進行方向だけで大幅に出す旧補間は廃止した。25 mm全域によるメイン下部ドラフト深さの変化も、コード比約6.5ポイントから約2.5ポイントへ縮小し、数mmのクリュー移動を誇張しない。

## 420 / 470のクラス別セール輪郭

現行の[International 420 Class Rules 2026](https://media.sailing.org/sailing/wp-content/uploads/2022/03/17092130/420_CR_2026-03-31.pdf)と[International 470 Class Rules 2025](https://www.sailing.org/wp-content/uploads/2022/03/470_CR_2025-09-01-II.pdf)のSection Gを比較した。単一輪郭の一様拡大では、クラス差を再現できない。

| 計測値 | 420 | 470 |
|---|---:|---:|
| メイン・リーチ長 | 5400 mm | 6265 mm |
| マスト上下限間距離（メイン高さの拘束） | 4900 mm | 5750 mm |
| メイン・フットボルトロープ長 | 1920 mm | 2200 mm |
| メイン・1/4幅 | 2130 mm | 2340 mm |
| メイン・1/2幅 | 1630 mm | 1790 mm |
| メイン・3/4幅 | 995 mm | 1050 mm |
| メイン・トップ幅 | 115 mm | 140 mm |
| メイン・バテン | 4本 | 3本 |
| ジブ・ラフ / リーチ / フット | 3500 / 3200 / 1750 mm | 4100 / 3750 / 1955 mm |
| ジブ・バテン | 最大3本（製品代表は3本） | 最大3本（製品代表は3本） |

実装を再監査した結果、ERSのクロス幅を同じ高さの水平コードとして置く方法は誤りと判断した。1/4・1/2・3/4幅はリーチ上の計測点から測る値であり、単純な高さ比ではない。そこで、420はNorth Sails M-12、470は2026年時点の現行N17-L26の公開製品シルエットを高さ1/16ごとに正規化し、現行クラス規則のラフ有効長、リーチ、トップ幅、ブーム外側点、ジブ三辺で実寸拘束する方式へ変更した。N17-L26はNorth Sailsが2024年パリ大会の金メダル使用モデルとして公開している。そこへ操作で変わるドラフト、最大位置、ツイスト、マストベンドを載せる。

### 3D幾何の再監査

旧ジブ面は各高さのコードを水平面で回転していたため、ラフは固定されてもヘッドとクリューの相対位置が崩れた。シート角70°ではクラス規則値に対し、リーチ直線距離が420で約14.7%、470で約14.1%長くなる。新モデルは固定ラフの局所座標系を作り、ラフ軸周りに面を回す。タック・ヘッド・クリューはラフ／リーチ／フット三辺から三角測量し、トップ幅もヘッドに直交する局所方向へ置く。5 / 20 / 45 / 70°の全テスト角で四つの基準距離を固定した。

メインの垂直寸法には、以前使っていたリーチ長ではなくマストのlower point–upper point距離を使う。リーチ長は外形の校正値であり、高さではない。World Sailing ERSのheadsail hoist heightは、マスト基準点から「ジブ・ハリヤード下端とマストの交点」までの計測値であり、セールのヘッド位置ではない。旧モデルはここを同一視してラフ長から逆算したため、ジブタックがデッキ金具から420で約626 mm、470で約397 mmも浮いていた。新モデルはタックを公式建造図のデッキ金具へ固定し、そこからハリヤード計測点へ向かう線上にクラス規則のラフ実寸だけを取る。この結果、ヘッドは計測上限より下にあり、ジブ全体が実艇側へ下がる。これはNorth Sails M-12の約8 ktベース設定で「フットのデッキに最も近い部分が触れる」、470のフルパワー設定で「フットがウォーターブレークに触れる」という指針とも整合する。上・中・下の断面値は区間外で固定せず、25 / 50 / 75%を通る連続曲線で0〜100%へ補間する。断面の深さ・最大位置・入口角・出口角は、各カメラの2D投影ではなく3Dコード基底で測る。

旧メイン面は、規則表の「フットボルトロープ長」420: 1920 mm / 470: 2200 mmをタック–クリュー間の直線長と誤読していた。その結果、アウトホールをブラックバンドまで引いてもクリューが外側点より420で480 mm、470で450 mmも前に残った。新モデルはボルトロープ長をセール構造の別寸法として保持し、420のタック切り込み20 mm、470の代表10 mmを経て、クリューを外側点から実際のアウトホール量0–25 mmだけ前へ置く。ブラックバンドは規則どおり10 mm幅の立体帯、クリューは二重円のアイとして表示する。

### ドラフトピークとストライプ表示の再監査

[North Sailsのセールパワー解説](https://www.northsails.com/en-us/blogs/north-sails-blog/upwind-sail-power-by-bill-gladstone)は、セール形状を迎角・深さ・ツイストの三要素で読み、深さを水平断面のふくらみとして扱う。[VSPARS](https://www.vspars.com/sails.aspx)などの飛行形状計測も、複数の水平ドラフトストライプごとにcamberとdraft positionを測る。つまり「最大ドラフト」はセール面上の縦の縫い目ではなく、各水平断面でコード線から最も離れた個別点である。

0.13.7までのメッシュは、各行の配列10番目を必ず最大ドラフト点にするため、コード方向のサンプル間隔をピーク位置に応じて歪めていた。さらに各行の10番目を高さ方向へ結んだ赤い稜線を表示したため、SIDEの斜め投影ではその線が曲面の「最も深い縦線」のように見え、各断面のピーク位置を誤読させた。

0.13.8ではコード方向を0–100%の等間隔メッシュへ戻し、各断面の正確な最大ドラフト点をメッシュ頂点とは別に断面式から生成する。深さと位置はその独立点を3Dコード基底で測り、上・中・下の3本の水平ストライプへそれぞれピークリングを置く。縦のピーク結線は廃止した。選択断面にはコード線、深さ寸法、ラフからの位置寸法を直接描き、隣に3断面すべての深さ／ピーク位置と比較値を固定表示する。これにより、カニンガム操作では下・中・上のピークが48/47/46%から45/43/41%へ前進するなど、高さごとの変化を同時に照合できる。

### セールシェイプを再現可能に確認する方法

[North SailsのSail Scan撮影手順](https://www.northsails.com/blogs/north-sails-blog/tips-for-taking-proper-sail-scan-photos)は、カメラをセールのフット中央へ置き、3本のドラフトストライプをラフからリーチまで収めるよう求める。メインはブーム中央を画面下へ含められる位置、ジブはフット中央のデッキ面近くからヘッドへ見上げる。したがって、本モデルの「ブーム後端カメラ」だけをセールシェイプ確認の標準視点とするのは不十分である。ブーム後端は上下の開きと後半形状を理解する補助視点として残し、実艇の観察位置は別に明示する。

[UK Sailmakers AccuMeasure](https://www.uksailmakers.com/wp-content/uploads/2024/03/UKSailmakersAccuMeasure2011.pdf)は、比較可能な写真には同じカメラ、画角、撮影位置が必要で、メインはブーム中央・少し風上、ジブはフット中央の低い位置を推奨する。また、同じ風でも方位や波で形が変わるため複数枚を撮り、風速・風向角・シート張力・リード位置・ハリヤード等を記録する。断面はコード線、最大カンバー、最大位置、15%／75%カンバー、断面間ツイストで読む。形状比較は一枚の印象ではなく、同じ条件と座標基準を持つ計測である。

0.13.9では、三方向モデルの直下へ実艇の観察位置と5段階の確認順を常設した。順序は「条件と視点を固定 → 3本を端まで追う → 深さとピークを読む → 断面間ツイストと入口／出口を読む → 一本だけ操作して操作前と比較」である。操作に連動する断面だけでなく、メイン／ジブと25・50・75%を手動選択できる。各断面に深さ、ピーク、下部断面に対する相対ツイスト、入口角、出口角を同時表示する。テルテールとリーチリボンは形状寸法ではなく、流れとツイストの結果を確認する別の手掛かりとして明記した。[North Sails 470 Tuning Guide](https://colorcode.northsails.com/sailing/wp-content/uploads/2017/05/470_tuning_guide_e01.pdf)も、上部リーチリボンをツイストの兆候として扱っている。

0.14.0では、後方ビューを「ブーム方位へ合わせた正投影」から、ブーム口の520 mm真後ろに原点を持つ透視投影へ変更した。カメラは口からブームを通してマストを見るため、手前の口が大きく、マストとヘッドが距離に応じて小さくなる。クローズの実視は本来細く見えるので横方向を変形せず、空白へ同じ3D面から切り出した上・中・下3断面を常設した。これにより「実際の後方像で上段バテンとブームの向きを見る」と「断面で深さとピークを読む」を混同せず同時に行える。

0.15.0では、目の位置をブーム口の520 mm後方に保ったまま、水平にマストを見る視線から、メイン全高の中央を見上げる視線へ変更した。水平視線では全高を収めるとメインが細い帯に潰れたためである。後方パネルはメイン専用とし、ジブ、フォアステイ、船体、独立3断面を外した。メインの面、ラフ、リーチ、25 / 50 / 75%のドラフトストライプ、ブーム口を同じ透視像で追う。視線の目標は現在形の頂点ではなく、ブーム軸とクラスのラフ長から作る固定点なので、カニンガム、アウトホール、バング、プラーを動かしてもカメラが形状を追って動かない。断面の正確な深さとピークは直下の計測パネルに残す。

[全尺度の飛行形状を計測した研究](https://sam.ensam.eu/handle/10985/11250)は、設計形状と実際の飛行形状に無視できない差があることを示す。そのため本実装は、公開規則と製品シルエットで拘束した学習モデルであり、メーカーの製造CAD、実艇の写真測量、CFD/FSIと「完全一致」するとは称さない。実艇一致の最終確認には、同じ風・艇・セールで撮影した420/470の校正画像と競技者・セールメーカーのレビューが必要である。

船体は[420 Building Specification Drawing 5 Issue J](https://media.sailing.org/sailing/wp-content/uploads/2022/07/02133245/420_BuildingSpec_2022-09Sep-01.pdf)と[470 Building Specification Plan 470-003](https://media.sailing.org/sailing/wp-content/uploads/2023/01/19160058/470_005_080623_GA.pdf)の平面・側面輪郭を座標化した。420は12、470は11の長手ステーションを持ち、船長、最大幅、マスト位置、ジブタック位置を別々に拘束する。旧実装は、外板の帯へ艇全体の輪郭を一枚の塗りで重ね、コックピットも暗い平面形で塞いでいた。これは三方向で同じ頂点を使っていても「艇体をモデリングした」とはいえない。

0.13.4では、外板面へトランサムを追加し、左右サイドデッキと凸型フォアデッキを別面で張る。開口内にはサイドタンク内壁、実際に低い位置を持つコックピット床、クラス別幅・長さのセンターボードケース、スウォート、メインシートトラックを置いた。ブレークウォーターは中心だけの記号ではなく、公式平面図と同様に両舷方向へ掃引し、高さを端へ向けてテーパーさせる。コックピット床はトランサム面へ接続し、フォアデッキのクラウンはステムで0へ収束させたため、船首・船尾に表示上の開口を残さない。同じ完成艇体の全頂点を上・斜め横へ投影し、視点別の記号的な船体イラストは使わない。0.14.0のブーム後方はセール形状へ集中するため、カメラ直前で巨大になるトランサムと船体を描かず、ブーム、マスト、セール、フォアステイだけを透視する。

公式建造図は全長・全幅・測定点・部材配置と許容範囲を規定するが、ビルダーの製造型CADや全長手位置の外板断面を公開していない。このため、規定値の間の外板フェアリング、コックピット床の細かな曲率、ブレークウォーターの選択可能な曲線は代表補間であり、特定メーカー艇の型と完全一致するという意味ではない。マストも旧来の太い中心線を廃止し、現行クラス規則の断面範囲（420: 前後50–75 mm・左右45–75 mm、470: 前後65–75 mm・左右55–75 mm）の中間値を使う12面の楕円スパーへ変更した。メーカー固有の押出材形状は公開規則から一意に定まらないため、断面は規則内の代表モデルと明示する。マスト単独を画面都合で太らせず、後方の実視像にも非等方な倍率を適用しない。

420のメインバテン位置はクラスルールDiagram 17のヘッドから1220 / 2220 / 3220 / 4220 mmの計測位置を高さへ換算した。470メインは3本という構成とクロス幅計測点に合わせた代表位置を使う。ジブは両クラスの規則が最大3本を許し、North Sailsの現行製品図でも3本構成を確認できるため、代表位置として25 / 50 / 75%へ短いリーチバテンを置く。後方カメラは実際のブーム方位へ追従し、ブーム口の後方からメイン中央を見上げる透視投影とする。上・中・下の形状差は、同じ像の3本のストライプと直下の計測断面で確認する。

### 見かけ風連動のメイン基本角

[North Sails Japan 420 M-12 Tuning Guide](https://www.northsails.co.jp/wordpress/wp-content/uploads/2026/03/420-M12-Tuning-Guide_j.pdf)は、オーバーパワーでない限りブームを艇のセンターへ持ってくること、10ノット付近でメインシート張力が最大になること、オーバーパワーになりブームが常にセンターから外へ出てからカニンガムを使うことを示す。[North Sails 470 Tuning Guide](https://colorcode.northsails.com/sailing/wp-content/uploads/2017/05/470_tuning_guide_e01.pdf)のトリミング表は、微風で中心線から風下へブーム幅3〜4本、フルパワーで中心線、オーバーパワー後は風速とともに風下へ出す段階を示す。[North Sails 470 Speed Guide](https://www.northsails.com/en-it/blogs/north-sails-blog/470-speed-guide)は、ダウンウインド強風でブームをシュラウドまで出すこと、弱風で見かけ風が前へ回るとメインを引き込む場合があることを説明する。

0.12.1までのモデルは、クローズだけをクラスガイドへ合わせた一方、55〜90°と90〜150°を真風角だけで補間していた。このため同じTWA 90°なら4 ktでも18 ktでも約45°となり、艇速で変わる見かけ風へ追従しなかった。NauticEd NEDが風向・風速ごとの最大艇速を正解フィードバックにし、ASA Sailing Challengeが見かけ風とトリムを独立モジュールとして結ぶのに対し、旧実装では表示した見かけ風がブーム角計算へ戻っていなかった。

0.13.0では次の連続モデルへ置き換えた。

1. 真風ベクトルへ艇速による向かい風を加え、AWA / AWSを計算する。
2. 上・中・下断面の前進力代理値から推定艇速を求め、艇速→見かけ風→前進力→艇速を収束まで反復する。
3. TWA 52°付近までは420 / 470ガイドのクローズ用ブーム位置を優先する。
4. リーチでは[Atterwindの公開モデル](https://github.com/flyinggorilla/simulator.atterwind.info)と同じく見かけ風に対する迎角を明示し、同リポジトリが実艇比較に近いとしている15°を学習用の代表値にする。すなわち基本値は `boom = AWA - 15°` である。
5. 52〜82°でクラス基準から見かけ風基準へsmoothstepで接続し、ブロードでは代表シュラウド位置（420: 78°、470: 80°）を越えない。
6. 空力代理値の前進方向への分解にも、従来のTWA近似ではなく反復後のAWAを使う。

基準形での代表出力は次の通り。角度は船体中心線を0°としたブーム角である。

| 艇種 | TWA | 4 kt | 10 kt | 18 kt | 主な規則 |
|---|---:|---:|---:|---:|---|
| 420 | 45° | 3.5° | 1.5° | 10.5° | 微風の小さな緩み→フルパワーでセンター→オーバーパワーで出す |
| 420 | 90° | 43.3° | 47.4° | 54.5° | AWA−15°。強風側は艇速/TWS比が下がり、AWAが後ろへ回る |
| 420 | 140° | 78.0° | 78.0° | 78.0° | 代表シュラウド上限 |
| 470 | 45° | 5.0° | 1.0° | 9.0° | 微風3〜4ブーム幅→フルパワーでセンター→オーバーパワーで出す |
| 470 | 90° | 41.6° | 45.7° | 53.0° | AWA−15° |
| 470 | 140° | 80.0° | 80.0° | 80.0° | 代表シュラウド上限 |

これは「風が強いほど常に出す」という表ではない。形状が改善して艇速が上がれば同じ真風でもAWAは前へ回り、リーチでは自動的にシートインする。実ブラウザ検証では、470・TWA 90°・4 ktで形状改善によりAWAが60.7°から58.7°へ前進し、ブーム角も45.7°から43.7°へ追従した。逆にTWSが増えて艇速がソフト上限へ近づくと艇速/TWS比が下がり、AWAが後ろへ回るためブームは出る。

15°、78°、80°は、セールカット、波、スピネーカー、ブライドル、シュラウド位置、乗員重量を較正した実測値ではない。Sailawayが公開説明で示すような実時間流体計算でもなく、Atterwindと同様に原理理解を優先した理想化である。画面にはTWA/TWS → AWA/AWS → ブーム角と現在のモードを並べ、学習者が仮定を確認できるようにした。

### ブーム後端の再現

現行420クラス規則F.3.5は外側点距離2400 mm、縦断面55〜89 mm、横断面32〜76 mmを定め、後端金具と10 mm以上の外側リミットマークを要求する。現行470クラス規則F.4.3〜F.4.4は外側点距離2650 mm、縦断面54〜72 mm、横断面38 mm以上を定め、後端金具を許可する。共通3Dモデルでは、420を70 × 55 mm、470を63 × 38 mmの代表的な合法断面とし、外側点の後ろに70 mmの代表後端金具を置く。70 mmはクラス規則値ではなく、後端面を観察するための表示仮定である。後端は外周と暗い内側面を別ポリゴンにする。透視投影のテストでは、420 / 470、クローズ / ビーム / ブロードの全条件で、目がブーム後端から520 mm後方に固定され、メイン中央の目標点が画面中心へ投影され、視線が上向きで、全メイン頂点が有限座標になることを固定する。水平ブーム視線の補助テストでは、手前の口の面積が奥のブーム断面より大きいことも維持する。

したがって、本モデルの観察優先は次の通りとする。

| 操作 | 最初に見る断面 | 主な変化 |
|---|---|---|
| カニンガム | メイン中部 | 最大ドラフト位置、入口／出口角、深さ |
| アウトホール | メイン下部 | 深さ |
| バング | メイン上部 | ツイスト／リーチ |
| 420 チョック | メイン下部 | ロワーマストベンドと深さ |
| 420 ジブ高さ | ジブ上部 | リード角とツイスト |
| 470 フォア／アフタープラー | メイン中〜下部 | 前後ベンドと深さ |
| 470 ジブリード前後 | ジブ上部 | ツイスト、下部深さ |

## 学習設計

- [PhET](https://phet.colorado.edu/translation/2720/about)は、操作の結果を即時に返す研究ベースのシミュレーションを設計原則としている。
- 物理のコンピュータ練習を扱った[APSの研究](https://journals.aps.org/prper/abstract/10.1103/PhysRevPhysEducRes.12.010134)では、単純で一般化可能な説明を伴う即時フィードバックが、特に準備度の低い学習者の成績改善に有効だった。
- 高校物理向けの[Predict–Observe–Explain教材研究](https://pubmed.ncbi.nlm.nih.gov/36406109/)は、予想・観察・説明を対話教材へ組み込んでいる。

このため、ドリルは「正解を表示→模倣」ではなく、予想 → 一本動かす → 操作前との差を観察 → 短い因果説明 → 別条件への転移、とする。

## カテゴリ首位水準の評価基準

1. **因果可視性**: 1操作後、5秒以内にどの断面が深く／浅く、前／後ろ、開く／閉じるか説明できる。
2. **同一モデル性**: 上・横・後ろ・断面・性能が同じセール面から計算され、頂点と計測値が一致する。
3. **クラス固有性**: 420のチョック／ジブ高さ、470のフォア／アフタープラー／ジブリードを一次資料と矛盾なく扱う。
4. **操作中の視認性**: デスクトップとモバイルの双方で三面図と断面を見たままスライダーを動かせる。
5. **学習移転**: クローズの設定をビーム／ブロードへ持ち越した誤りを、優先順を使って修正できる。
6. **共同利用**: 同じ条件と形状をURLで再現し、授業・チーム・コーチングで比較できる。
7. **誠実性**: 推定速度を実測ポーラやCFDと称さず、仮定と未モデル化要因を明記する。
8. **品質**: キーボード操作、色以外の区別、モバイル390px、テスト、性能・アクセシビリティ監査を通す。

## 今回の優先順位

1. 操作前ゴーストと深さ／最大位置／ツイスト差分
2. 入口角／出口角の追加
3. 現在の条件と形を復元できる共有URL
4. 三面図を固定したモバイル操作
5. 実利用者テストで語彙・誤解・モデル係数を再較正

トリム操作欄は、調整中に学習者の視線と手の位置をずらさない。艇種ごとの操作順を固定スロットとして保ち、優先番号・完了・待機の同じ高さのステータス帯だけを更新する。

最後の5は公開Web調査だけでは完了しない。競技者・指導者による実艇妥当性確認を次の検証段階とする。
